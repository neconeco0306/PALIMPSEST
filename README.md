# PALIMPSEST / 余白生態系

操作パネルのない、触り方をローカルに記憶するブラウザ作品。

## 起動
`index.html` をブラウザで開くだけ。外部依存・ビルド不要。

## 入力
- タップ: 粒子と音
- ドラッグ: 傷/流れを形成
- 長押し: 放射状の「開花」
- キーボード入力: 文字を物理オブジェクトとして落とす
- 放置: 世界側から稀に現象が起きる

## 設計の核
- Canvas 2Dのみ。WebGL/Three.js不使用。
- Web Audio APIで音源ファイルなしの手続き的サウンド。
- localStorageに「作品の状態」ではなく主に操作傾向を保存。次回は絵を復元せず、性質だけ継承する。
- UI設定を排除。ユーザーが世界を調整するのではなく、世界がユーザーに適応する。
- アセットなし、外部APIなし、オフライン動作。
